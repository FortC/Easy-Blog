恭喜，你已经在用 Easy Blog 写第一篇文章了。这一篇是自带的示例，看完就可以删掉。

## 这个站能干什么

- **访客看到纯静态页**：首页 gzip 不到 15KB，小带宽服务器也秒开
- **站长在 /admin 在线写**：写完点「保存并发布」，1-2 秒后全站更新，不用碰命令行
- **访客填昵称就能评论**：不用注册、不用登录 GitHub，数据是服务端一个 JSON 文件
- **可选 AI 助手**：配个大模型 Key，右下角多一个能陪你聊天的导览员

## 写作就是写 Markdown

正文随便写，代码块、表格、引用都是现成的：

```go
func main() {
    // 整个后端就一个 Go 文件几兆大，没有数据库
    log.Println("hello, easy blog")
}
```

> 引用块长这样。写博客最重要的不是排版，是开始写。

## 接下来你可以

1. 打开后台，把站点标题、昵称、简介改成你自己的
2. 删掉这篇示例文章，写下第一篇真正属于你的
3. 有问题翻 README，或者直接看源码——总共也没几行
