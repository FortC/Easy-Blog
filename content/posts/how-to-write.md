两种写法任选：后台 `/admin` 在线编辑，或者本地写 Markdown 丢进 `content/posts/`。这篇把字段和语法都列一遍。

## 文章开头的字段

```yaml
---
title: 文章标题
date: "2026-01-02T20:00:00+08:00"   # 必须是这种带引号的 ISO 格式
categories: [建站]                    # 分类，一个就够
tags: [Markdown, 写作]                # 标签随便加
pin: true                             # 可选：置顶在文章列表第一位
description: 一句话摘要，列表页和分享卡片都用它
---
```

## 正文语法速查

**行内代码**用反引号：`hugo --minify`。

表格：

| 字段 | 必填 | 说明 |
|------|------|------|
| title | 是 | 列表和标题栏都显示它 |
| date | 是 | 排序和时间线归档靠它 |
| description | 建议 | 不写会自动截正文前 60 字 |

列表、粗体、斜体、删除线都是标准 Markdown。图片直接写相对路径放 `static/img/` 下，记得标宽高。

## 发布

后台写完点「保存并发布」，服务器自动 Hugo 构建、原子切换，1-2 秒生效。构建失败会自动回滚，线上不受影响——所以放心写，写坏了大不了删了重来。
